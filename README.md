# Logic in Databases

This repository contains my work from the Logic in Databases practical course at university.

The project focuses on using logic-based approaches for representing, querying, and processing information in databases. The practical work includes concepts related to preferences, logical query processing, and the implementation of database operations using SQL and related techniques.

## Main Topics

* Logic in Databases
* Database preferences
* Preference representation
* Preference queries
* Preference evaluation
* Winnow operator
* Python
* Database query processing

The repository contains the practical task documents as well as the implementations developed during the course.
